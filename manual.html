Vista general del sistema

El sistema tiene tres partes: el Admin (solo para vos), los Portales Públicos (para clientes), y la Base de Datos en Supabase que conecta todo.

🏠 Admin

Panel privado donde manejás todo: seres, sesiones, programas, marketing, calendario y más. Solo accesible desde tu computadora abriendo el archivo 1_ADMINISTRACION/index.html.

🌐 Portales Públicos

Páginas que ven tus clientes: portal del ser, portal del programa, onboarding, recursos JCC, registro. Están en Vercel en lacasadelprofit.vercel.app.

🗄️ Supabase

Base de datos donde se guarda todo. Admin y portales leen y escriben ahí. No necesitás entrar a Supabase normalmente — el admin lo maneja por vos.

Flujo típico de trabajo

1
Llega un prospecto
Se registra en /registro.html o /registro_jcc.html → aparece automáticamente en Admin → Seres como prospecto.
2
Completás el onboarding
Le mandás el link /onboarding.html → lo llena → aparece en Admin → Programas → Registros.
3
Creás la inscripción
Desde Admin → Journey → inscribís al ser en un programa. Le das acceso al portal del programa.
4
Se hacen sesiones
Las cargás en Admin → Sesiones. El ser las ve en su portal y puede completar el formulario post-sesión.
5
Seguimiento continuo
El ser accede a su portal del programa para ver avance, hábitos, semanas y comunicarse con vos.

Seres

Es tu base de contactos. Cada persona que pasa por el sistema — prospecto o cliente — tiene un registro acá.

Crear un ser manualmente

1
Admin → Seres → + Nuevo Ser
Completá nombre, email y celular como mínimo.
2
Definí el origen
De dónde vino: Instagram, WhatsApp, referido, etc.
3
Guardá
El ser queda disponible para asignar sesiones y programas.
Tip: Cuando alguien se registra desde /registro.html o /registro_jcc.html, se crea solo automáticamente como prospecto. No necesitás crearlo a mano.

Campos principales

CampoPara qué sirve
NombreSe usa en los portales y en las sesiones
EmailEs el login del Portal del Ser
ProspectoSi está marcado, es alguien que aún no compró
EtapaNuevo / Contactado / Calificado / Cliente / Inactivo
OrigenDe dónde llegó — útil para saber qué canal funciona

Sesiones

Registrás acá cada sesión que hacés — antes, durante o después de realizarla.

Cargar una sesión

1
Admin → Sesiones → + Nueva Sesión
Elegí el ser, el tipo de sesión, fecha y hora.
2
Asigná facilitador
Si hay más de un facilitador en el equipo.
3
Estado de la sesión
Pendiente → cuando se confirma. Completado → cuando ya se realizó. Cancelado si no fue.

Estados de sesión

Pendiente Completado Cancelado Reagendado
Formulario post-sesión: Cuando una sesión está completada, el ser puede llenar un formulario de integración desde su portal. Ves las respuestas en Admin → Sesiones → detalle de la sesión.

Programas

Los programas son el contenido estructurado que ofrecés. Podés crear varios programas y inscribir seres en ellos.

Crear un programa

1
Admin → Programas → + Nuevo Programa
Nombre, descripción, ícono, duración en semanas/meses.
2
Definí las semanas
Desde Journey → cada semana tiene desafíos, hábitos y material.
3
Inscribí seres
Journey → Inscribir Ser → elegís quién y desde cuándo empieza.

Pestaña Registros

Dentro de Programas hay una pestaña 📋 Registros que muestra todos los onboardings completados. Desde ahí podés:

👁
Ver todo
Ver las respuestas completas del cliente + agregar tus notas de facilitador (impresión, bloqueos, hipótesis, ratings).
🔗
Vincular
Asociar ese onboarding a un programa específico.

Onboarding

El formulario de onboarding es lo primero que completa un nuevo cliente del programa PDC (Proyecta · Dirige · Construye).

Flujo completo

1
Mandás el link al cliente
lacasadelprofit.vercel.app/onboarding.html
2
El cliente llena 5 preguntas
Nombre, email, objetivos, situación actual, compromisos, logro esperado y tiempo disponible.
3
Se guarda en Supabase
Automáticamente, al tocar "Finalizar ✓". No necesitás hacer nada.
4
Lo ves en el Admin
Admin → Programas → pestaña Registros → aparece con estado "Pendiente".
5
Agregás tus notas
Tocás "Ver todo" → completás impresión, bloqueos, hipótesis, potencial y disposición (1-10).
6
Vinculás al programa
Tocás "Vincular" → asignás a qué programa corresponde → queda marcado como "Asignado".

Calendario

Vista de todas las sesiones organizadas por fecha. Tiene dos modos.

📅 Vista Mensual

Muestra el mes completo con puntos de colores por sesión. Si hay muchas en un día muestra "+X más".

📆 Vista Semanal

Muestra los 7 días de la semana con todas las sesiones del día visibles, con hora incluida.

Navegación: Usá las flechas ‹ › para moverte entre meses/semanas. El botón "Hoy" vuelve a la fecha actual.

Regalos

PDFs y recursos que ofrecés gratuitamente. Se muestran en /regalos.html y en /recursos_jcc.html.

Crear un regalo

1
Admin → Regalos → + Nuevo Regalo
Nombre, ícono, descripción y URL del PDF (Google Drive, Supabase Storage, etc.).
2
Elegí la marca
"JCC" → aparece solo en recursos_jcc.html. "LCP" → aparece en regalos.html. "Ambos" → en los dos.
3
Ordenalo
Usá las flechas ↑ ↓ para definir el orden en que aparecen.
Seguimiento: Cada descarga queda registrada en Supabase. Lo ves en Marketing → Regalos.

Portal del Ser

Portal privado para clientes de sesiones individuales. Se loguean con su email.

Qué ve el cliente

✨ Mis Sesiones

Lista de todas sus sesiones: pendientes, completadas, canceladas. Puede filtrar por estado.

📅 Próxima sesión

Cuántos días faltan para la próxima sesión agendada.

🎁 Regalos

Acceso a los regalos disponibles sin salir del portal.

📅 Agendar sesión

Formulario para pedir una nueva sesión → llega a vos por WhatsApp.

Login: El cliente escribe su email → el sistema lo busca en la tabla Seres → si existe, entra. No hay contraseña.

Recursos JCC

Página pública de Juan Cruz Consciencia con preguntas expansivas y regalos.

✦ Pregunta del momento

Muestra una pregunta aleatoria por usuario. El botón "Otra pregunta" rota por todas las disponibles.

Preguntas expansivas

Todas las preguntas activas cargadas en Admin → Comunidad. Se agregan desde ahí.

🎁 Regalos para vos

Regalos con marca "JCC" o "Ambos". En grilla de 2 columnas.

Estadísticas: Los clicks en todos los botones quedan registrados. Se ven en Admin → Marketing → Estadísticas.

Base de datos

Supabase es donde se guarda toda la información. No necesitás entrar normalmente — el admin lo maneja. Pero si necesitás revisarla directamente, acá están las tablas.

TablaQué guarda
seresTodos los contactos: prospectos y clientes
sessionsTodas las sesiones registradas
programasLos programas creados
inscripcionesQué ser está en qué programa, con su progreso
onboardingsFormularios de onboarding completados por clientes
herramientasTipos de sesión disponibles
regalosPDFs y recursos descargables
regalo_eventosRegistro de descargas y clicks en botones

Importante: Todas las tablas usan el mismo patrón: id + data (jsonb). Toda la información del registro va dentro del campo data.

Deploy — Actualizar la web

Cuando se hacen cambios en los archivos, hay que subirlos a GitHub para que Vercel actualice la web automáticamente.

Cómo actualizar un archivo

1
Ir al repositorio en GitHub
github.com/lacasadelprofit-dot/Lacasadelprofit
2
Navegar a la carpeta del archivo
Ej: 2_PORTALES_PUBLICOS → recursos_jcc.html
3
Editar o reemplazar el archivo
Tocás el lápiz ✏️ para editar, o subís el archivo nuevo arrastrándolo.
4
Hacer commit
Escribís un mensaje breve de qué cambió y confirmás.
5
Esperar 1-2 minutos
Vercel detecta el commit y despliega automáticamente. La web queda actualizada.
Vercel Analytics: Para activar el seguimiento de visitas, entrá al dashboard de Vercel → tu proyecto → pestaña Analytics → habilitarlo. Es gratis y da visitas, visitantes únicos y de dónde vienen.
